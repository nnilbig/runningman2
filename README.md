# 跑者阿傑 v0

一部約十分鐘、可以「跑」的短片。從背後陪著阿傑跑過十年，每章做一個選擇，決定劇情與結局。

這是 v0 試玩版。

## 怎麼玩

用瀏覽器直接打開 `index.html`，手機直式、橫式都可以。全程不需要操作，只在故事停下時選一個選項。

- 右上角「下一章 ›」可以跳到下一章
- 網址加上 `#ch1` 到 `#ch8` 可以從指定章節開始
- 選擇會記在瀏覽器裡，第八章的結局依第一到第六章的選擇決定

## 技術

- 單一 HTML 檔，three.js r128（從 cdnjs 載入）
- 場景、人物、跑步動作、聲音都是程式即時產生，沒有外部素材
- 字幕字體：Noto Serif TC（Google Fonts）
